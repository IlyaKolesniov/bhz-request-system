# BHZ Request System

Веб-система учёта заявок на установку видеонаблюдения.

## Что это за продукт

Единое веб-приложение, в котором менеджер создаёт заявку клиента, прикрепляет фотографии объекта, указывает количество камер и список оборудования, назначает монтажника и дату установки. Монтажник видит всю информацию до выезда на объект.

## Для кого

Для компании BHZ (установка и обслуживание систем видеонаблюдения). Заказчик: руководитель компании. Пользователи: менеджеры, монтажники, руководитель. Работа через браузер на компьютере и телефоне.

## Какую проблему решает

Сейчас данные о заявках разбросаны по WhatsApp, Excel и телефонам сотрудников. Из-за этого обработка заявки занимает 20–30 минут, примерно в 2–3 заявках из 10 монтажнику приходится звонить менеджеру, а в 1–2 случаях из 10 на объекте не хватает оборудования.

## Цели первой версии

| Показатель | Сейчас | Цель |
|---|---|---|
| Время обработки заявки | 20–30 мин | 5–10 мин |
| Заявки с уточняющим звонком монтажника | 20–30% | менее 5% |
| Случаи нехватки оборудования на объекте | 10–20% | менее 5% |

Бюджет: до 500 000 ₸. Срок: 1–2 месяца.
